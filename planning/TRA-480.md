# TRA-480: AI Planner ignores event/venue-centric trip intent

**Linear:** https://linear.app/travyl/issue/TRA-480
**Branch:** `feature/TRA-480`
**Status:** In Progress

## Goal

When a user's trip is centered around a specific event or venue (e.g. "4 days in Las Vegas for EDC", "3 days at Disneyland"), the AI planner should schedule that event/venue as the primary purpose of the trip, not fill the itinerary with generic sightseeing.

## Root Cause

Three pipeline stages fail to enforce `must_visit`:

1. **Stage 2 (Data Acquisition):** Never searches specifically for `must_visit` items — only does generic "things to do" queries
2. **Stage 3 (Scoring):** No score boost for `must_visit` POIs — they can be outranked and filtered out
3. **Stage 4 (Scheduler):** `_find_must_visit_indices` works but has nothing to find if Stages 2-3 dropped the POI

## Changes

### Stage 2: `data_acquisition.py`
- Added `_fetch_must_visit_pois()` — searches SerpAPI for each `must_visit` item specifically
- For venue-centric items (Disneyland, theme parks), creates multi-day POIs with 8hr visit duration
- For event-centric items (EDC, Coachella), creates multi-day POIs with 6hr blocks
- Falls back to synthetic POI at destination center if SerpAPI returns nothing
- Integrated into `acquire()` parallel fan-out
- Must-visit POIs are prepended to the POI list (highest priority)

### Stage 3: `scoring.py`
- Added `_is_must_visit()` helper — matches POIs by `must_visit` tag or name overlap
- Must-visit POIs get +200 score boost (vs max ~80 for normal POIs)
- Must-visit POIs bypass category caps — never filtered out
- Must-visit POIs survive even if their category is in `avoid_categories`

### Stage 4: `scheduler.py`
- Added `_is_multiday_venue()` to detect venue/event POIs (visit_duration >= 360min)
- New "step 0" in greedy assignment: pin multi-day venue POIs to specific days BEFORE meals
- Day pinning: "Disneyland (Day 1)" goes to day 1, "(Day 2)" to day 2, etc.
- Remaining must-visit items still handled in step 2 as before

## Test Cases

| Prompt | Expected behavior |
|--------|-------------------|
| "4 days in Las Vegas for EDC" | 3 EDC evening slots + 1 free day with complementary activities |
| "3 days at Disneyland in Anaheim" | 2 full Disneyland days + complementary activities |
| "5 days in Rome, must see Colosseum" | Colosseum scheduled with 2hr duration, rest is normal planning |

## Known Issues

- Venue/event keyword lists are hardcoded — could miss niche events. Acceptable for MVP; future improvement could use LLM classification.
- Multi-day event duration is estimated, not looked up from real event data.
